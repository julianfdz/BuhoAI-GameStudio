# Gameplays y vídeos

Los vídeos (`.mp4`, `.webm`, `.mov`, `.mkv`) tienen un reproductor pensado para revisar partidas:

| Qué | Cómo |
|---|---|
| Adelantar o atrasar 10 s | botones o teclas **J** / **L** |
| Pausa | **K** o espacio |
| Velocidad | 0,5× a 4× |
| Vídeo anterior o siguiente de la carpeta | **Anterior / Siguiente**, **RePág / AvPág** o **Alt + ← / →** |
| Seguir con el siguiente al acabar | casilla «Al acabar, el siguiente» |

Debajo sale la tira con todos los vídeos de la carpeta, con su fotograma y duración. Anterior / Siguiente también vale para imágenes, modelos y sonidos.
