# Compartir un proyecto

El proyecto es una carpeta, así que se comparte como cualquier carpeta:

1. Pon la carpeta del proyecto en **Google Drive** (u OneDrive, Dropbox o git) y compártela con permiso de edición.
2. Tu compañero instala Búho Game Studio y añade la carpeta compartida a su unidad («Añadir acceso directo a Mi unidad»).
3. En la app: **Abrir carpeta** y elige esa carpeta. Verá los mismos assets, IDs, fichas, estados, tareas, comentarios e historial.
4. Cada uno pone su nombre en **Conectores** para firmar.

A tener en cuenta:

- las miniaturas se rehacen en cada equipo;
- el enlace a Unity es una ruta de tu PC: cada uno enlaza su copia;
- si dos personas cambian estados o comentarios a la vez, Drive puede crear una copia en conflicto de un `.json` de `.buhostudio/`.
